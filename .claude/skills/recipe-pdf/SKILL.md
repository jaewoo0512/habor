# 레시피 PDF 만들기

레시피 하나를 A4 PDF로 렌더링한다. 모든 레시피가 같은 서식(제목 → 리드문 → 조리시간·분량·난이도 박스 → 재료 표 → 단계 → 성공 포인트 → 응용)을 공유하도록 `scripts/recipe_pdf.py` 하나로 렌더링한다.

## 순서

1. **원본 확인.** [week-1/quests/레시피북](../../../week-1/quests/레시피북)에 해당 `.md`가 있는지 먼저 본다.
   - 있으면 **내용을 그대로** 옮긴다. 문장을 다듬거나 재료를 더하지 않는다.
   - 없으면 기존 `.md` 파일 하나를 읽어 톤과 구성을 맞춰 새로 쓴다. 이때 `.md`도 함께 만들지는 **묻고** 결정한다(기본은 PDF만).
2. **레시피 JSON 작성.** 스크래치패드에 아래 스키마대로 `<이름>.json`을 쓴다. `assets/example-recipe.json`이 완성된 예시다.
3. **렌더링.**
   ```bash
   python .claude/skills/recipe-pdf/scripts/recipe_pdf.py <recipe.json> "week-1/quests/레시피북/<제목>.pdf"
   ```
   출력 파일명은 md와 같은 규칙(`15분-간장버터-치킨덮밥.pdf`처럼 공백 대신 `-`)으로 짓는다.
4. **확인.** pypdf로 페이지 수를 확인한다. 보통 1~2쪽이며, 3쪽을 넘으면 내용이 과한 것이니 리드문/응용을 줄인다.
   ```bash
   python -c "from pypdf import PdfReader; print(len(PdfReader('경로.pdf').pages))"
   ```
   콘솔에 `extract_text()` 결과를 찍으면 한글이 깨져 보이는데, 이는 터미널 인코딩 문제일 뿐 PDF 자체는 정상이다. 글자 확인이 필요하면 PDF를 직접 열어 본다.

## JSON 스키마

```json
{
  "title": "15분 간장버터 치킨 덮밥",
  "lede": "한두 문장짜리 소개. 이 요리가 왜 15분에 되는지 한 줄로.",
  "time": "15분",
  "serves": "2인분",
  "level": "쉬움",
  "ingredients": [
    ["닭다리살 (정육)", "400g"],
    ["소스", null],
    ["간장", "2.5큰술"]
  ],
  "steps": [
    ["밑준비", "0분", "재료 손질. <b>강조</b>는 b 태그로."],
    ["닭 굽기", "2분", "..."]
  ],
  "tips": ["<b>핵심 한 줄.</b> 이유 한 문장."],
  "variations": ["닭 대신 <b>두부</b>"],
  "footer": "habor 레시피북"
}
```

- `ingredients`: `[이름, 분량]` 쌍. 분량이 `null`이면 **소제목 행**(예: "소스", "크럼블")으로 음영 처리되어 한 칸으로 합쳐진다.
- `steps`: `[제목, 경과시간, 설명]`. 경과시간은 조리 시작 기준 누적 시간(`"0분"`, `"6분"`)이고, `""`나 `null`이면 생략된다.
- `tips` / `variations`: 없으면 생략 가능. 항목마다 굵게 시작하고 이유를 붙이면 읽기 좋다.
- `footer`: 생략 시 `habor 레시피북`.
- 텍스트에는 ReportLab 인라인 마크업 `<b>`, `<i>`, `<font>`, `<sub>`, `<super>`만 쓴다. 마크다운 `**굵게**`는 그대로 출력되니 변환해서 넣는다.

## 서식 규칙

- **유니코드 첨자(₂, ²) 금지** — 폰트에 글리프가 없어 검은 네모로 나온다. `<sub>`/`<super>`를 쓴다.
- 한글 폰트는 맑은 고딕을 자동 등록한다(윈도우 밖에서는 Apple SD Gothic / 나눔고딕으로 폴백). 새 환경이면 `scripts/recipe_pdf.py`의 `FONT_CANDIDATES`에 경로를 추가한다.
- 팔레트와 여백은 스크립트 상단 상수(`ACCENT`, `INK`, `BAND` 등)에 모여 있다. 레시피별로 색을 바꾸지 말 것 — 레시피북 전체가 한 벌로 보여야 한다.

## 여러 개 한 번에

레시피북 전체를 뽑을 때는 레시피마다 JSON을 만들고 스크립트를 반복 호출한다. 여러 레시피를 한 PDF로 묶어달라는 요청이면 각각 만든 뒤 pypdf로 병합한다(`pdf` 스킬 참고).
