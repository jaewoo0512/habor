# 15분 들기름 김치 비빔국수

익은 김치 하나로 승부하는 새콤 고소한 비빔국수. 불 앞에 서는 시간은 5분뿐.

- **조리 시간**: 15분
- **분량**: 2인분
- **난이도**: 매우 쉬움

## 재료

| 재료 | 분량 |
| --- | --- |
| 소면 | 200g |
| 잘 익은 김치 | 1컵 (잘게 썰기) |
| 김치 국물 | 3큰술 |
| 오이 | 1/2개 (채 썰기) |
| 달걀 | 2개 |
| 김가루 | 한 줌 |
| **양념** | |
| 들기름 | 2큰술 |
| 고추장 | 1큰술 |
| 설탕 | 1큰술 |
| 식초 | 1큰술 |
| 간장 | 1작은술 |
| 다진 마늘 | 1/2작은술 |
| 통깨 | 1큰술 |

## 만드는 법

1. **물 올리기 + 달걀 (0분)**
   냄비에 물을 올리고, 동시에 다른 냄비에 달걀을 넣어 삶기 시작한다 (반숙 8분).

2. **양념장 만들기 (2분)**
   볼에 양념 재료를 모두 넣고 잘 섞는다. 여기에 썬 김치와 김치 국물을 넣어
   **미리 버무려 둔다.** 김치에 양념이 배는 시간이 맛을 좌우한다.

3. **오이 준비 (5분)**
   오이를 얇게 채 썰어 소금 한 꼬집에 절였다가 물기를 살짝 짠다.

4. **면 삶기 (7분)**
   물이 끓으면 소면을 넣고 3분. 끓어 넘치려 하면 찬물 반 컵을 부어 가라앉힌다.

5. **찬물 헹구기 (11분)**
   삶은 면을 체에 밭쳐 **얼음처럼 차가운 물에 손으로 박박 비벼가며** 헹군다.
   표면 전분을 완전히 씻어내야 면이 쫄깃하고 안 붇는다. 물기는 꽉 짠다.

6. **비비기 (14분)**
   면을 양념 볼에 넣고 손으로 조물조물 버무린다. 젓가락보다 손이 훨씬 잘 섞인다.

7. **담기 (15분)**
   그릇에 담고 오이채, 반으로 자른 달걀, 김가루를 올린 뒤 들기름 조금 더.

## 성공 포인트

- **면은 차가운 물에 비벼 헹군다.** 미지근하게 헹구면 면이 늘어져 실패한다.
- **양념은 면보다 먼저.** 김치가 양념을 머금을 시간을 준다.
- 신 김치일수록 맛있다. 안 신 김치면 식초를 1/2큰술 더.

## 응용

- **참치캔** 하나를 기름 빼고 넣으면 든든한 한 끼
- 면 대신 **밥**을 비비면 김치 비빔밥
- **삶은 콩나물** 한 줌을 넣으면 아삭한 식감 추가
