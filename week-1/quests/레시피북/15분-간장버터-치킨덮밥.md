# 15분 간장버터 치킨 덮밥

닭다리살을 바삭하게 구워 짭조름한 간장버터 소스에 굴린 덮밥. 밥만 있으면 완성되는 한 그릇 요리.

- **조리 시간**: 15분
- **분량**: 2인분
- **난이도**: 쉬움

## 재료

| 재료 | 분량 |
| --- | --- |
| 닭다리살 (정육) | 400g |
| 따뜻한 밥 | 2공기 |
| 대파 | 1/2대 (어슷 썰기) |
| 버터 | 1.5큰술 |
| 식용유 | 1큰술 |
| 달걀노른자 | 2개 (선택) |
| 통깨 · 쪽파 | 약간 |
| **소스** | |
| 간장 | 2.5큰술 |
| 맛술 | 2큰술 |
| 설탕 | 1큰술 |
| 다진 마늘 | 1작은술 |
| 물 | 2큰술 |

## 만드는 법

1. **밑준비 (0분)**
   닭다리살을 한 입 크기로 썰고 키친타월로 물기를 제거한 뒤 소금·후추 약간.
   소스 재료를 작은 그릇에 모두 섞어둔다.

2. **닭 굽기 (2분)**
   팬에 식용유를 두르고 **중강불**로 달군 뒤 닭을 껍질 쪽이 아래로 가게 펼쳐 넣는다.
   **3분 동안 건드리지 않는다.** 자꾸 뒤집으면 껍질이 바삭해지지 않는다.

3. **뒤집기 (6분)**
   껍질이 진한 갈색으로 바삭해지면 뒤집어 2분 더 굽는다. 팬에 고인 기름은 한 번 닦아낸다.

4. **소스 졸이기 (9분)**
   불을 중불로 낮추고 섞어둔 소스를 붓는다. 보글보글 끓으면 대파를 넣고
   2~3분간 소스가 걸쭉해지며 닭에 윤기 나게 코팅될 때까지 굴린다.

5. **버터 마무리 (13분)**
   불을 끄고 버터를 넣어 잔열로 녹이며 섞는다.
   **불을 끄고 넣어야** 버터 향이 날아가지 않고 소스가 부드럽게 유화된다.

6. **담기 (15분)**
   그릇에 밥을 담고 닭과 소스를 올린 뒤 노른자를 얹고 쪽파·통깨를 뿌린다.

## 성공 포인트

- **닭 물기 제거 + 안 건드리기.** 바삭한 껍질의 90%가 여기서 결정된다.
- **버터는 무조건 마지막, 불 끄고.** 태우면 텁텁해진다.
- 소스가 너무 짜면 물 1큰술, 묽으면 30초 더 졸인다.

## 응용

- 닭 대신 **돼지 목살**이나 **두부** (두부는 물기 빼고 노릇하게)
- 마지막에 **모차렐라 치즈**를 올려 뚜껑 덮고 1분 → 치즈 덮밥
- 밥 대신 **우동면**을 넣고 볶으면 간장버터 야끼우동
