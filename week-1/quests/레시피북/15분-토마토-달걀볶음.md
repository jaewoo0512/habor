# 15분 토마토 달걀볶음 (시홍스차오지단)

중국 가정식의 대표 반찬. 재료 3개로 만드는데 밥 두 공기가 사라지는 마성의 요리.

- **조리 시간**: 15분
- **분량**: 2인분
- **난이도**: 매우 쉬움

## 재료

| 재료 | 분량 |
| --- | --- |
| 완숙 토마토 | 3개 (중간 크기) |
| 달걀 | 4개 |
| 대파 | 1/2대 |
| 식용유 | 3큰술 (나눠서) |
| 설탕 | 1큰술 |
| 소금 | 1/2작은술 |
| 굴소스 | 1작은술 (선택) |
| 참기름 | 1작은술 |

## 만드는 법

1. **손질 (0분)**
   토마토를 6~8등분 웨지로 썬다. 대파는 송송.
   달걀은 소금 한 꼬집과 함께 **거품이 살짝 일 정도로** 충분히 푼다.

2. **달걀 볶기 (3분)**
   팬에 식용유 2큰술을 넣고 **연기가 살짝 날 만큼** 강불로 달군다.
   달걀물을 붓고 5초 기다렸다가 가장자리부터 크게 휘저어 반숙 상태(약 70% 익음)에서
   바로 접시에 덜어낸다. **여기서 완전히 익히면 나중에 퍽퍽해진다.**

3. **토마토 볶기 (6분)**
   같은 팬에 남은 기름 1큰술과 대파를 넣어 향을 낸 뒤 토마토를 넣는다.
   중강불에서 3~4분, 토마토가 무르며 즙이 나올 때까지 볶는다.

4. **간하기 (11분)**
   설탕·소금·굴소스를 넣고 섞는다. **설탕이 핵심** — 토마토 신맛을 잡고 감칠맛을 끌어올린다.
   국물이 자작하게 생기면 딱 좋다.

5. **합치기 (13분)**
   덜어둔 달걀을 다시 넣고 30초~1분만 크게 섞는다. 달걀 덩어리가 부서지지 않게 살살.

6. **마무리 (15분)**
   불을 끄고 참기름을 두른다. 뜨거운 밥 위에 국물째 얹어 먹는다.

## 성공 포인트

- **달걀은 두 번에 나눠 익힌다.** 반숙에 빼놨다가 마지막에 합치는 게 부드러움의 비결.
- **설탕 1큰술을 겁내지 말 것.** 단맛이 아니라 균형을 잡아준다.
- 팬은 **충분히 뜨겁게.** 미지근한 팬에 달걀을 부으면 눌어붙는다.

## 응용

- **새우** 5~6마리를 3번 단계에 추가
- 국물을 넉넉히 만들어 **국수**에 부으면 토마토 달걀 국수
- 마지막에 **고수**나 **바질**을 올리면 향이 확 달라진다
