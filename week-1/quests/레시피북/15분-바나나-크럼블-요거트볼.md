# 15분 카라멜 바나나 크럼블 요거트볼

프라이팬에 바나나를 굽고 오트밀을 볶아 얹는 디저트. 오븐도, 반죽도, 기다림도 없다.

- **조리 시간**: 15분
- **분량**: 2인분
- **난이도**: 매우 쉬움

## 재료

| 재료 | 분량 |
| --- | --- |
| 바나나 | 2개 (약간 익은 것) |
| 그릭 요거트 | 300g |
| 버터 | 1.5큰술 (나눠서) |
| 흑설탕 | 2큰술 |
| 꿀 or 메이플시럽 | 1큰술 |
| 시나몬 가루 | 1/4작은술 (선택) |
| 소금 | 한 꼬집 |
| **크럼블** | |
| 오트밀 (롤드 오트) | 4큰술 |
| 견과류 (호두·아몬드) | 3큰술 (굵게 다지기) |
| 흑설탕 | 1큰술 |

## 만드는 법

1. **밑준비 (0분)**
   바나나를 세로로 반 가른 뒤 다시 반으로 자른다. 견과류는 굵게 다진다.
   요거트는 미리 그릇 2개에 나눠 담아 냉장고에 둔다.

2. **크럼블 볶기 (2분)**
   마른 팬에 오트밀과 견과류를 넣고 **중약불**에서 3분간 볶는다.
   고소한 냄새가 올라오고 색이 살짝 나면 버터 1/2큰술과 흑설탕 1큰술을 넣어
   1분 더 볶은 뒤 **접시에 펼쳐 식힌다.** 팬에 두면 눅눅해진다.

3. **카라멜 만들기 (7분)**
   같은 팬에 버터 1큰술과 흑설탕 2큰술, 소금 한 꼬집을 넣고 중불로 녹인다.
   보글보글 끓으며 걸쭉해질 때까지 1분.

4. **바나나 굽기 (9분)**
   바나나를 자른 면이 아래로 가게 넣고 **2분간 건드리지 않는다.**
   가장자리가 진한 갈색이 되면 뒤집어 1분 더. 시나몬을 뿌린다.

5. **조립 (14분)**
   차가운 요거트 위에 따뜻한 바나나를 올리고 팬에 남은 카라멜 소스를 끼얹는다.
   크럼블을 듬뿍 뿌리고 꿀을 두른다.

6. **바로 먹기 (15분)**
   **차가운 요거트 + 따뜻한 바나나 + 바삭한 크럼블**, 이 온도·식감 대비가 이 디저트의 전부다.
   만들자마자 먹는다.

## 성공 포인트

- **너무 익은 바나나는 피한다.** 검은 반점이 조금 있는 정도가 딱 — 물러지면 팬에서 뭉개진다.
- **크럼블은 반드시 팬 밖에서 식힌다.** 바삭함이 여기서 갈린다.
- **요거트는 차갑게, 바나나는 뜨겁게.** 미리 조립해두면 밍밍해진다.

## 응용

- 바나나 대신 **사과**(얇게 슬라이스, 3분 더 굽기)나 **복숭아**
- 카라멜에 **럼 1작은술**을 더하면 어른용 디저트
- 요거트 대신 **바닐라 아이스크림** → 5초 만에 죄책감 있는 버전
- 크럼블을 넉넉히 만들어 밀폐용기에 두면 일주일간 그래놀라로 사용 가능
